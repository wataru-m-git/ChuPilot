# ChuPilot - Docker Setup Guide

This is the Dockerized version of ChuPilot (a mouse colony management application). Follow this guide to launch the application easily.

## System Requirements

- Docker Desktop, or Docker + Docker Compose
- A web browser (Chrome, Firefox, Safari, etc.)

## Quick Start

### 1. Create the environment configuration file (.env.local)

For security reasons, `.env.local` (which contains secret keys) is not included in the repository.
Create it by copying the template:

```bash
cp .env.local.example .env.local
```

Next, open the `.env.local` you just created and be sure to set the following two values:

1. **AUTH_SECRET** (the key used to sign/encrypt sessions. Required)
   Paste the string generated by the following command into `AUTH_SECRET=`:

   ```bash
   openssl rand -base64 32
   ```

2. **ADMIN_DEFAULT_PASSWORD** (the administrator's initial password)
   Set any secure password (if left empty, `ChangeMe@123456` will be used).

> ⚠️ If `AUTH_SECRET` is leaked, impersonation login becomes possible.
> Never paste the generated value into a public repository, social media, etc.

### 2. Start the Docker container

Run the following command in the project root:

```bash
docker compose up
```

On the first run, it will take a few minutes as the image is built and dependencies are installed.

**Example output:**

```
mouse-colony-app  | ▲ Next.js 14.2.5
mouse-colony-app  | - Local:        http://localhost:3333
mouse-colony-app  | - Environment: production
```

### 3. Access via browser

Open the following URL in your browser:

```
http://localhost:3333
```

### 4. Log in

Log in with the initial account:

- **Username**: admin@local.lab
- **Password**: ChangeMe@123456

Be sure to change the password after your first login.
Do not connect to a public network before changing the initial password in a production environment.

## Common Commands

### Start the application (in the background)

```bash
docker compose up -d
```

### Check the logs

```bash
docker compose logs -f
```

### Stop the application

```bash
docker compose down
```

### Rebuild the container (after changing code)

```bash
docker compose up --build
```

### Access the database (Prisma Studio)

To launch Prisma Studio inside the container:

```bash
docker compose exec app npx prisma studio
```

## Usage

### Dashboard
The home screen after login displays the following information:
- Total number of mice
- Housing status of each cage
- Statistics by strain

### Managing individual mice

#### Adding a new record
1. Select "Mice" from the side menu
2. Click the "New" button
3. Enter the required information:
   - Mouse ID
   - Strain name
   - Sex
   - Date of birth
   - Current cage ID
4. Click "Save"

#### Editing / deleting records
1. Click the target individual in the mouse list
2. Use the "Edit" button to update the information, or "Delete" to remove it

### Managing cages

#### Registering a cage
1. Select "Cages" from the side menu
2. Click the "New" button
3. Enter the cage ID, capacity, etc.
4. Click "Save"


### Managing strains

#### Registering strain information
1. Select "Strains" from the side menu
2. Click the "New" button
3. Enter the strain name, description, etc.
4. Click "Save"

### Importing data

#### Bulk registration from an Excel file
1. Select "Import" from the side menu
2. Download the template (if needed)
3. Fill in the information in the Excel file
4. Specify the file with "Choose File"
5. Click the "Import" button
6. Review the contents in the preview, then click "Confirm"

**Note**: Always back up your data before importing.

#### Exporting data
- You can export to CSV/Excel using the "Export" button on the screen

## Main Features

- **Mouse management**: Register, edit, and delete individual records
- **Cage management**: Manage housing cages
- **Strain management**: Classify mice by strain
- **Excel import**: Bulk registration feature
- **Dashboard**: Visualize housing status

## Troubleshooting

### If port 3333 is already in use

Edit the `ports` section of `docker-compose.yml`:

```yaml
ports:
  - "8080:3333"  # Change the external port to 8080
```

Then access `http://localhost:8080` in your browser.

### If a database error occurs

```bash
# Remove the container and restart
docker compose down -v
docker compose up
```

### If a build error occurs

```bash
# Clear the cache and rebuild
docker compose down
docker system prune -a
docker compose up --build
```

## Database Backup

The `data/mouse_colony.db` file is stored as a persistent volume.

### Backing up directly from the host machine

```bash
cp data/mouse_colony.db data/backup_$(date +%Y%m%d).db
```

- After changing code, rebuild with `docker compose up --build`
- If you change the database schema, run the Prisma migrations
